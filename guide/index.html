Step-by-Step Printer Setup & Hardware Troubleshooting

Apne printer ki physical status check karein aur niche diye gaye steps ko follow karke setup complete karein.

Step 1: Printer ke paas jayein aur LED Light check karein

Sabse pehle apne printer ke paas jayein aur dekhein ki Power ya Warning LED status kya bata raha hai:

  • Agar LED Light Red/Yellow Blink kar rahi hai: Printer me paper jam, low ink, ya cartridge door khula hone ka issue ho sakta hai. Paper tray check karein aur door properly close karein.
  • Agar LED Light Solid Green/Blue hai: Printer physical level par ready hai. Ab apne computer screen par jayein.
Step 2: Apne Brand ke according Driver Download karein

Computer par aane ke baad apne printer brand ki official website se correct software/driver download karein:

  • Apne printer model number ko note karein (jaise: DeskJet 2300, EcoTank L3150, etc.).
  • Official brand portal par jakar apna Windows/Mac version select karke official driver software download karein.

Step 4: Driver Download/Install hone ke baad bhi Fix na ho toh kya karein?

Agar driver install karne ke baad bhi printer offline dikha raha hai ya setup BPMC 202 (Print Queue/Spooler Blockage) par stay ho gaya hai, toh apne computer me ye step karein:

  • Keyboard par Windows + R press karein, services.msc type karke Enter dabayein.
  • List me Print Spooler dhundhein, uspar Right-Click karke Restart par click karein.
  • Uske baad USB Cable nikal kar dobara lagayein ya Router restart karein.
Important Note on Code BPMC 202 / Spooler Freeze: Yeh error tab aata hai jab Windows Queue me purani file stuck ho jati hai. Command Prompt (Admin) khol kar net stop spooler aur net start spooler run karke bhi isse reset kiya ja sakta hai.
