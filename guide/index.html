Before You Start: Identify Your Printer

Before installing software or changing settings, identify the exact printer model. A manufacturer may offer many printers that require different drivers and setup procedures.

  • Find the model number on the front, back, bottom, or inside label of the printer.
  • Identify the connection type: USB, Wi-Fi, Ethernet, or another supported method.
  • Check your operating system and version in Windows Settings.
  • Note any warning lights, display messages, or error codes.
  • Keep the printer manual available if you need model-specific instructions.
Helpful tip: Record the exact error message instead of relying only on the colour of a warning light. Indicator meanings differ between models.

1. Check the Printer's Physical Condition

Check the printer itself before troubleshooting Windows. Software changes cannot fix every problem, especially if the printer has a paper jam, power issue, or hardware warning.

1 Check the power and status lights
  • Confirm that the power cable is securely connected.
  • Turn the printer on and wait for its startup process to finish.
  • Check the display or status lights for warning messages.
  • Consult the exact model's manual to understand blinking or coloured indicators.
2 Check paper, ink, toner, and covers
  • Load supported paper in the correct orientation.
  • Adjust the paper guides without bending the paper.
  • Check ink or toner status, where applicable.
  • Ensure cartridge doors and access panels are closed.
  • Look for paper-jam warnings or other displayed errors.
Safety warning: Do not force jammed paper out of the printer. Follow the manufacturer's instructions. Laser printer components can remain hot after use. Never touch electrical components with wet hands.

2. Download the Official Printer Driver

A printer driver helps Windows communicate with the printer. An incompatible, missing, or outdated driver can cause detection problems, printing errors, or missing printer features.

Official manufacturer support websites

Open the manufacturer's support website and search for your exact printer model. Review the operating system and compatibility information before downloading anything.

HP Printers Official drivers and software ↗ Canon Printers Official product support ↗ Epson Printers Official downloads and manuals ↗ Brother Printers Official support and downloads ↗
1 Follow the correct download process
  1. Open the manufacturer's official support website.
  2. Enter the exact printer model number.
  3. Select your operating system if prompted.
  4. Review the available driver or setup software.
  5. Download and run the compatible installer.
  6. Follow the on-screen instructions to complete setup.
Security tip: Avoid unknown driver download websites and suspicious executable files. Download software from the printer manufacturer or a trusted operating-system source.

Some printers work with drivers built into Windows. A separate full-feature software package is not required for every printer.

3. Set Up a Printer Using a USB Cable

A USB connection allows a compatible printer to communicate directly with a computer.

1 Connect the printer
  1. Turn on the printer and wait for it to become ready.
  2. Inspect the USB cable for visible damage.
  3. If using a manufacturer installer, connect the cable when instructed.
  4. If the printer is not detected, try another USB port on the computer.
  5. If available, test with a compatible replacement cable.
2 Add the printer in Windows 11
  1. Open Start and select Settings.
  2. Go to Bluetooth & devices.
  3. Select Printers & scanners.
  4. Select Add device.
  5. Choose your printer when it appears and complete the setup.
3 Add the printer in Windows 10
  1. Open Settings.
  2. Go to Devices and select Printers & scanners.
  3. Select Add a printer or scanner.
  4. Choose your printer when detected.
  5. Follow the prompts to finish installation.

If Windows cannot find the printer, check the cable, try another USB port, and verify whether the exact model requires a manufacturer driver.

4. Set Up a Wireless Wi-Fi Printer

A Wi-Fi printer can print from compatible devices over a local network. The setup procedure depends on the printer's control panel and wireless features.

1 Connect the printer to Wi-Fi
  1. Open the printer's wireless or network settings.
  2. Select the wireless setup option, if available.
  3. Choose your Wi-Fi network from the displayed list.
  4. Enter the network password when requested.
  5. Wait for the printer to confirm its network connection.
2 Add the printer to your computer
  1. Connect your computer to a network that can access the printer.
  2. Open Windows Settings and select Printers & scanners.
  3. Select Add device or Add a printer or scanner.
  4. Select your printer when it appears.
  5. Complete setup and print a test page.

Wi-Fi versus Wi-Fi Direct

Wi-Fi through a router: The printer and computer communicate over a shared home or office network.

Wi-Fi Direct: A supported printer can create a direct wireless connection with a compatible device. The connection process and internet availability depend on the model.

If the printer cannot be discovered, check whether the computer and printer are on accessible networks. Guest networks, client isolation, or separate wireless networks can prevent discovery. A router factory reset should not be the first troubleshooting step.

5. Print a Test Page

A test page helps verify that Windows can send a print job to the selected printer.

  1. Open Settings and select Printers & scanners.
  2. Select the installed printer.
  3. Open its available printer properties or management options.
  4. Select Print test page if that option is available.
  5. Check whether the page prints correctly.
Successful setup: Windows detects the printer, the test page prints, and no active warning remains.

If a test page works but an application cannot print, check the selected printer, document settings, page range, and the application's print dialog.

6. Fix a Printer That Shows Offline

An offline status means Windows cannot currently communicate with the printer as expected. It does not automatically mean the printer is damaged.

1 Check the connection
  1. Check the printer's power and ready status.
  2. Reconnect the USB cable if it is a wired printer.
  3. Verify the wireless connection if it is a Wi-Fi printer.
  4. Turn the printer off, wait about 30 seconds, and turn it back on.
  5. Restart the computer if necessary.
2 Check the offline setting
  1. Open the printer's queue from Windows Settings.
  2. If the classic queue window is available, open its Printer menu.
  3. Check whether Use Printer Offline is selected.
  4. If selected, clear it when the printer is properly connected and ready.
3 Check pending jobs and the selected printer
  • Cancel jobs that are stuck in the queue.
  • Confirm that the correct printer is selected in the application.
  • Check for duplicate printer entries.
  • If the problem continues, consider removing and reinstalling the printer.

7. Fix Print Jobs Stuck in the Queue

The Windows print queue manages pending documents. A failed job can sometimes prevent later documents from printing.

Method 1: Cancel pending jobs

  1. Open Settings and select Printers & scanners.
  2. Select your printer and open its print queue.
  3. Right-click a pending job and select Cancel.
  4. Repeat for other stuck jobs and wait for the queue to clear.

Method 2: Restart Print Spooler

  1. Press Windows + R.
  2. Type services.msc and press Enter.
  3. Find Print Spooler in the Services list.
  4. Right-click it and select Restart, if available.
  5. Check the queue and try printing again.
Use the manual queue-clearing method in the next section only if normal cancellation and restarting the service do not resolve the problem.

8. Troubleshoot Windows Print Spooler Errors

Print Spooler is a Windows service that manages print jobs. If it stops or crashes, documents may remain stuck in the queue and printing may stop working.

Method A: Restart the service

  1. Press Windows + R.
  2. Type services.msc and press Enter.
  3. Find Print Spooler.
  4. Right-click it and select Restart.
  5. If the service is stopped, select Start if available.
  6. Try printing a test page.

Method B: Clear the spool folder manually

Use this method only when cancelling jobs and restarting Print Spooler have not resolved the issue.

  1. Open Services by running services.msc.
  2. Right-click Print Spooler and select Stop.
  3. Open File Explorer.
  4. Navigate to the folder shown below.
  5. Delete the pending files inside the PRINTERS folder. Do not delete the folder itself.
  6. Return to Services and start Print Spooler again.
  7. Print a test page.
C:\Windows\System32\spool\PRINTERS
Clearing the spool folder removes pending print jobs. Do not delete unrelated system files. If you cannot access the folder, verify that the service is stopped and that you have the necessary permissions.

Optional: Restart Print Spooler using commands

If you are comfortable using an administrator Command Prompt, run these commands one at a time: 

net stop spooler
net start spooler

To run Command Prompt as administrator, open Start, search for Command Prompt, and select Run as administrator. Review any confirmation prompts.

If the service repeatedly crashes, outdated or conflicting printer drivers may need investigation. Avoid removing drivers unless you have identified the relevant printer and understand the consequences.

9. Fix Blank, Faded, Blurry, or Streaked Prints

Poor print quality may result from ink or toner problems, paper settings, a clogged printhead, or a hardware issue.

Problem What to Check
Blank pages Ink or toner status, cartridge installation, document content, and driver settings.
Faded text Ink or toner levels, supported paper, and print-quality settings.
Lines or streaks Manufacturer-recommended printhead cleaning or maintenance.
Smudged output Paper compatibility, paper-type settings, and handling instructions.
Incorrect layout Paper size, orientation, scaling, and application settings.
Repeated printhead-cleaning cycles can consume additional ink. Follow the manufacturer's recommended maintenance procedure for your exact model.

10. Fix Paper Jams and Paper-Feed Problems

  1. Check the printer display for the reported jam location.
  2. Turn off the printer if the manufacturer's instructions recommend it.
  3. Carefully remove accessible jammed paper according to the manual.
  4. Check for torn paper fragments and overloaded paper trays.
  5. Load supported paper and adjust the paper guides.
  6. Close all access panels and restart the printer if appropriate.
Never force paper out or disassemble internal components without the correct instructions. If paper is inaccessible or the printer remains jammed, contact the manufacturer or a qualified technician.

Official Microsoft resource: Printer troubleshooting in Windows ↗

11. Fix a Printer That Windows Cannot Detect

For USB printers

  • Confirm that the printer is powered on.
  • Reconnect the USB cable and try another port.
  • Test a compatible replacement cable if available.
  • Check Device Manager for the printer or an unknown device.
  • Install the compatible driver if the model requires one.

For Wi-Fi printers

  • Confirm that the printer is connected to Wi-Fi.
  • Check that the computer can access the printer's network.
  • Restart the printer and router if necessary.
  • Check whether a guest network or network isolation is blocking discovery.
  • Verify network settings if the printer's IP address has changed.

Run Windows printer troubleshooting

On Windows 11, the Get Help app may provide an automated printer troubleshooter. Available troubleshooting options vary by Windows version.

Official Microsoft guide: Fix printer connection problems ↗

12. Understand Printer Error Messages and Codes

Error messages can vary by printer brand, model, operating system, and connection type. A code should not be assigned a specific meaning without checking the relevant documentation.

Message or Symptom Initial Check
Printer Offline Check power, connection, queue, and offline settings.
Print Spooler Not Running Check the Print Spooler service in Windows Services.
Printer Not Found Check USB or network connectivity and device discovery.
Paper Jam Follow the manufacturer's instructions for the reported jam location.
Driver Unavailable Verify the printer model, operating system, and compatible driver.
Unknown Numeric Code Search the exact code on the manufacturer's official support website.
About BPMC 202: Do not automatically identify this code as a Print Spooler error. Verify the exact code, printer model, full message, and where the error appears before choosing a fix. General spooler troubleshooting is appropriate only when the symptoms indicate a Windows printing queue or service problem.

13. Printer Maintenance and Prevention

  • Use supported paper types and sizes.
  • Store paper in a clean, dry place.
  • Protect the printer from excessive dust and moisture.
  • Follow the manufacturer's recommended maintenance procedures.
  • Download drivers and firmware only from trusted sources.
  • Avoid factory resets unless simpler troubleshooting has failed and you understand what settings may be lost.
  • Check the selected printer, paper size, and page range before printing important documents.
Good practice: Keep a note of the printer model, connection type, and official support page. This information can make future troubleshooting easier.

Frequently Asked Questions

Can a printer work without a separate driver?

Some printers work with drivers built into Windows or supported standard printing protocols. Advanced features may require manufacturer software.

Why does my printer show Offline when it is powered on?

Check the cable or network connection, offline settings, print queue, and Print Spooler service. For wireless printers, verify network connectivity.

What happens when I restart Print Spooler?

Restarting the service refreshes Windows print-job management and may resolve temporary printing problems. It does not fix every printer issue.

Must my printer and computer use the same Wi-Fi?

For typical local-network printing, both devices need to be on networks that can communicate. Wi-Fi Direct and some managed network setups work differently.

Should I use third-party driver-updater software?

Start with the printer manufacturer's official support website or Windows Update. Avoid unverified driver tools.

Should I reset the printer to factory settings?

Not as a first step. Check the connection, paper, print queue, and driver first. A factory reset may erase saved network and configuration settings.

What should I do if none of these steps work?

Record the printer model, operating system, exact error message, and steps already tried. Then consult the manufacturer's official support documentation or a qualified technician.
